# LiveWell Coach — Portal track (🟢 Navigator)

**Portal and Navigator are now one guide.** Each lab contains click-by-click Navigator steps, available current
illustrations and all required copyable text. Steps without a suitable current capture are fully described in text.
Follow the main lab pages below; there is no separate walkthrough to keep open.

## Naming rules

Keep your own `livewell-<initials>` agent through Labs 0-3. The optional Lab 1 intake uses a separate
`livewell-<initials>-intake` agent. Never edit shared `livewell-demo-*` or `livewell-workshop-*` agents.
